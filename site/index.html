읽는 법

하루(또는 5·20·60·120거래일) 동안 누가 어느 섹터를 순매도하고 순매수했나를 한 장에 그린다. 주체 칸을 누르면 그 주체 하나의 섹터별 순매도·순매수만 남고, 기관은 투신·연기금 등 세부로 펼친다.

01왼쪽은 넘긴 쪽, 오른쪽은 넘겨받은 쪽

왼쪽 주체는 그 섹터를 순매도했고, 오른쪽 주체는 순매수했다. 같은 주체가 양쪽에 다 나온다 — 순매도한 섹터들의 합과 순매수한 섹터들의 합은 서로 다른 숫자다.

02띠 하나는 (주체, 섹터) 한 칸

섹터와 섹터, 주체와 주체를 잇지 않는다. 누가 누구에게 넘겼는지는 데이터에 없다. 빛 점도 섹터 칸에서 사라지고 반대쪽에서 새로 난다 — 칸을 지나가지 않는다.

03잔여를 숨기지 않는다

네 주체 합이 0 이 아닌 몫은 잔여 칸으로 따로 선다. 네 주체에 나눠 넣지 않는다. 금액은 순매매 수량 × 종가로 환산한 근사다.

  • 넘긴 쪽(순매도) 파랑 · −
  • 넘겨받은 쪽(순매수) 빨강 · +
  • 개인
  • 외국인
  • 기관
  • 기타법인
  • 잔여

자기 키로 보는 법

이 사이트에는 합성 데모만 있다. 실제 숫자는 각자 자기 키움 REST API 키로 받아 자기 기기에서 본다 — 시세·수급 데이터는 대부분 제3자 재배포를 허락하지 않아서다.

  1. 데모부터 띄운다

    DB 도 키도 없이 터미널 화면이 뜬다. 숫자·이름은 난수다.

    uv tool install git+https://github.com/younghwan91/sector-flow
sw-flow --demo        # 섹터 표 — 맨 앞에 [합성 데모]

  2. 체크아웃하고 키를 둔다

    키움 REST API 앱키를 .env 에 적는다. 값은 읽기만 하고 화면에 찍지 않는다.

    git clone https://github.com/younghwan91/sector-flow && cd sector-flow && uv sync
# .env — 저장소에 올리지 않는다(.gitignore)
KIWOOM_APP_KEY=<앱키>
KIWOOM_APP_SECRET=<시크릿>

  3. 섹터 몇 개를 받는다

    읽기 전용 조회만 부른다. 섹터 두 개(약 100종목) 300거래일이 호출 약 600건이다. 같은 키를 쓰는 다른 프로그램이 쉬는 시간에 돌린다.

    uv run sector-flow-collect --max-calls 1500 backfill --db my.db --sectors "<섹터>,<섹터>" --days 300

  4. 지도를 짓는다

    sqlite 에서 리포트 묶음을 만들고 그 묶음으로 지도를 짓는다. 브라우저로 연다.

    uv run python scripts/sector_flow.py --db my.db --json payload.json
uv run python scripts/sector_map.py --payload payload.json --html map.html

받은 데이터와 그린 그림은 그 기기에만 둔다. 이용·보관·공유는 각자 데이터 제공자(KRX·증권사 등)와 맺은 약관을 따른다.

지금은 섹터 몇 개 크기의 조각을 받는다. 전 시장을 짧게 받는 길은 준비 중이다 — 진행은 docs/byo.
