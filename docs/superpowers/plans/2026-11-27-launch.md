## 초안 — Show HN

Title: `Show HN: Sector-flow – who sold which Korean stock sector to whom, as one map`

> I built a small open-source tool that draws daily KOSPI/KOSDAQ investor flows as a bipartite map:
> net sellers (foreigners, institutions, retail) on the left, sectors in the middle, net buyers on the right.
> Ribbon width is the won amount. It never links sector to sector — net sums don't say who traded with whom.
>
> Demo (synthetic data, no signup): https://younghwan91.github.io/sector-flow/
> Terminal: `uvx sector-flow --demo`
>
> Public pictures are synthetic because KRX data can't be redistributed; with your own Kiwoom API key it
> collects into a local sqlite and draws the same map on your machine. Each report re-counts itself through
> 13 verification layers, and the checks are mutation-tested. It reports what happened, not what will happen.
>
> Code (MIT, Python): https://github.com/younghwan91/sector-flow

## 초안 — awesome-quant PR

줄(`## Visualization`, 알파벳 자리):
`- [sector-flow](https://github.com/younghwan91/sector-flow) - Daily investor-type flow map for KOSPI/KOSDAQ sectors (net sellers → sector → net buyers), with a terminal UI and a synthetic browser demo.`

본문(CONTRIBUTING 의 근거 블록):
- **Use case**: see which investor groups (foreign, institutional sub-types such as pension funds, retail) net-sold and net-bought each Korean market sector on a given day, at the won amount.
- **Implementation**: Python, stdlib-only TUI; HTML map; demo at https://younghwan91.github.io/sector-flow/ and `uvx sector-flow --demo`.
- **Maintenance**: CI with tests and mutation checks on every PR, tagged releases, CHANGELOG.
- **Data constraints**: real data needs the user's own Kiwoom OpenAPI key (collected locally); public outputs are synthetic.
- **Relationship**: I am the author.
