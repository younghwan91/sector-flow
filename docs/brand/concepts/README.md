# 브랜드 시안 기록

2026-11-21 에 수급 지도의 모양을 정하려고 만든 시안 셋이다(전부 합성 데모, 브라우저로 연다). 지금의 지도는 A 의 밤 바탕·빛 입자에
B 의 헤드라인·숫자 띠·주석을 얹은 것이다 — 최종 모습은 [`docs/images/map-demo.png`](../../images/map-demo.png)·[`map-demo.gif`](../../images/map-demo.gif),
고른 과정은 [설계 §3.2·§7](../../superpowers/specs/2026-11-21-flow-map-brand-design.md).

| 시안 | 모양 | 판정 | 한 줄 이유 |
|---|---|---|---|
| [`a-neon.html`](a-neon.html) | 밤 바탕, 띠를 따라 흐르는 빛 입자 | **채택** — 바탕·입자 | 넘기고 넘겨받는 모습을 말 없이 움직임으로 보인다(입자가 섹터 칸을 지나지 않게 고쳐 썼다). |
| [`b-editorial.html`](b-editorial.html) | 신문 1면 — 큰 헤드라인·숫자 띠·주석 | **채택** — 헤드라인·숫자 띠·주석 | 숫자와 단위가 그림보다 먼저 읽히고, 차분한 말투가 '관측' 이라는 성격과 맞는다. |
| [`c-bold.html`](c-bold.html) | 굵은 색면·큰 글씨(K-볼드) | **버림** — 조사 처리(은/는·으로/로)만 가져왔다 | 과열된 말투로 읽힐 수 있어 법적으로 가장 안전한 길과 어긋난다. |

세 시안이 같이 버린 것도 있다.

- **그림 구조** — 셋 다 "순매도 섹터 → 주체 → 순매수 섹터" 로 그렸다. 섹터마다 네 주체 합이 0 에 가까워 같은 섹터가 같은 크기로
  양쪽에 서는 거울이 됐다. 지금은 주체 → 섹터 → 주체이고 주체 칸을 누르면 그 주체 하나의 섹터를 본다(설계 §3.1).
- **제목의 말** — "돈은 어디로 흘렀나" 처럼 돈이 섹터 사이를 옮겨 간 것처럼 읽히는 말은 쓰지 않는다. 관측되는 것은 (주체, 섹터)
  순매수뿐이다. 피할 말은 `src/sectorflow/wording.py` 의 `MAP_AVOID` 가 지킨다.

시안 파일은 그때 모습 그대로 둔다(고치지 않는다). 새 화면은 시안이 아니라 브랜드 가이드와 지금의 지도 템플릿을 따른다.
