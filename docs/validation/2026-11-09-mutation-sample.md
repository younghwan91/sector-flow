# 무작위 변이 표본 — 검사가 선언 안 한 버그를 무는가 (2026-11-09)

완료 조건: 표본 100개에서 **실질 생존**(등가·설정값을 뺀 생존)이 한 자릿수 %.

`tests/mutations.toml` 은 적어둔 버그만 증명한다. 여기서는 `scripts/mutation_sample.py` 가 AST 에서 변이를 무작위로 뽑는다(비교·논리·산술 연산자,
숫자 +1, `if` 부정, `return None`). 실행된 적 없는 줄은 뽑지 않는다. 대상은 네 묶음 25개씩: `digest.py`, `trust_page.py`, `collect/*`,
`sector_flow`·`verify_report` 등의 main 이후 바뀐 줄. TUI·`storage` 는 표본 밖이다.

```
uv run --extra dev pytest -q --cov --cov-report=json:coverage.json
uv run --extra dev python scripts/mutation_sample.py --seed 10 --per 25 --workers 5 --out s10.json
```

코드·커버리지가 바뀌면 같은 시드도 다른 변이를 뽑는다. 같은 변이는 `--replay`.

리뷰 보고의 "74/100 생존" 은 잡힌 수를 잘못 옮긴 것이다. 리뷰 로그는 잡힘 74·묶음 생존 26·전체 pytest 뒤 생존 25 다.

**시드 9·10 은 고치기 전에 잰 숫자다.** 표본에서 나온 진짜 생존은 전부 검사를 더해 잡았고(replay: 시드 7 은 94 잡힘·6 생존, 시드 8 은 생존 19 중
14 잡힘, 시드 9·10 은 생존 33 중 17 잡힘 — 남은 16 은 아래 등가·설정값), 그래서 replay 숫자는 표적 수정의 회귀 확인일 뿐 강도의 추정이 아니다. 강도의 추정은 새 표본뿐이다.

한 자릿수에는 닿았지만 여유가 없다. 8/100 의 95% 구간(Wilson)은 약 4~15% 라 "10% 아래" 를 증명하지 않는다. 시드마다 고쳐도 8~13 사이에서 크게 줄지
않은 것은, 남은 생존이 흩어진 개별 분기라 한 번에 잡히지 않는다는 뜻이다. 다음 표본도 비슷할 것으로 본다.

## 생존 분류

**등가** — 어떤 입력으로도 관측 결과가 같다.

- `digest.py:421` `default=0.0` → `1.0`: 뒤의 `or 1.0` 이 어차피 1 로 만든다. `:416` `v > 0` → `>=`: 앞에서 `not v` 로 0 을 걸렀다. `:255` `v >= 0` → `>= 1`: `|v| ≥ 9999.5` 안쪽이다.
- `equiv.py:333`·`:164`: 동률에서 어느 쪽 예시를 남기느냐뿐. `:145` 허용오차 경계. `dart.py:116` `sleep(0)`.
- `trust_page.py:150`: 읽는 키가 `commit`·`finalize` 둘뿐이라 더 들어와도 안 읽는다.
- `run.py:178`: 한 종목 안에서 첫 자리(코드)가 같다. `fetch.py:180`: `depth` 를 아무도 안 읽는다.
- `verify_report.py:2417`: 동률 정렬 — 대조는 집합으로 한다. `:2966` 슬라이스 끝이 배열 끝을 넘을 뿐. `:2979` 실수 경계.
- `digest.py:590`·`trust_page.py:689`: `--help` 설명 줄.

**설정값** — 1 을 더해도 버그가 아니고, 값을 못 박는 검사는 동어반복이다.

- `trust_page.py:68` 창 60일, `write.py:23` 스키마 판(읽는 쪽 없음), `run.py:140` 쪽 상한 여유, `digest.py:510` 브라우저 상한, `digest.py:64` 글 상한,

**실질** — 전부 검사를 더했고 `tests/mutations.toml` 의 "표본 2·3·4" 와 리뷰 표본 절에 변이로 남겼다. 주로 결측 기본값(`or 0`), 경계(`>=`), 표시 문구,
수집기의 페이징·공시 선택이다. 눈에 띄는 것: 끝값 대조만 있어 양쪽이 같이 움직이면 안 보이던 **검증기의 주도주 문턱·수정 폭**, 행 순서에 기대 통과하던 **DART 늦은 공시 선택**.

## 표본 도구의 함정

첫 재실행은 99/100 잡힘이었고 그중 6건(위의 시드 7 등가·설정값)이 거짓이었다. 소스 글자를 대조하는 `test_mutation_spec`·`test_docs_refs` 가 변이와 무관하게 빨개졌고, `TMPDIR` 이
클론 안이면 "git 밖" 을 전제한 검사가 빨개졌다. 그래서 얕은 검사를 빼고, 잡았다는 검사를 변이를 뺀 트리에서 다시 돌려 확인하고, `TMPDIR` 을 클론 밖에 둔다. 메모리를 먹는 변이
(`dart.py:241`)가 SIGKILL 을 냈으므로 프로세스 메모리 상한도 건다.
