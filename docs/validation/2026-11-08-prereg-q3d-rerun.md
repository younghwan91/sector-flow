# 사전등록 덧붙임 — Q3d 앞날 관계를 고친 정의로 다시 (2026-11-08)

원 사전등록: [2026-11-08-prereg.md](2026-11-08-prereg.md) Q3d. 결과를 보기 전에 고정한다.

## 왜 다시 하나
첫 Q3d(결과 문서 "8칸 모두 기준 미달")는 같은 날 찾은 결함 2·3 이 든 정의로 계산했다 — 섹터 수익률을
`flu_rt` 로 잇고(09-14 이후 이어 쓸 수 없다), 시총을 수정주가 × 늦은 주식수로 만들었다. 지표(가속의 분모,
x 의 Δv)와 **앞날 수익률 자체**가 둘 다 이 정의를 탄다. PR #5(e8d8d12)의 정의로 다시 잰다.

## 바꾸는 것(정의만)
- 일별 종목 수익률 = `daily_bars_adjusted` 종가 비. 없으면 결측, 가중치에서도 뺀다.
- 시총 = 원 종가(`supply_demand.close`, 없으면 `daily_bars_raw`) × as-of 주식수, 스냅샷 뒤 분할·병합·감자(8·16·64)를
  1/(1+upd_rt/100) 배로 다시 센다(`storage.market_cap_asof_bulk` 와 같은 식).
- 지표 계산은 머지된 `scripts/sector_numbers.py`(얇은 섹터 k 적합 제외, 단독 통과 G 0.5).

## 그대로인 것
- 표본: 2017-01 이후, 기준일 5거래일 간격 격자, 260일 창. 현재 상장 종목·현재 섹터 라벨(생존편향 그대로 — 한계로 적는다).
- 주 판정 8칸: 지표 {20일 가속(기관), x20, G20, 20일 기관 임펄스} × 지평 {5, 20}거래일, `전체` 시장, 10종목 미만 섹터 제외,
  offset 0(비겹침 첫 격자).
- 통계: 날짜별 횡단면 순위 IC, 날짜 안 섹터 라벨 섞기 1000회 널(양측), 표본 전·후반 부호.
- 판정 "관계 있다" = 널 p < 0.05 **그리고** 전·후반·전체 부호 같음. 아니면 "증거 없음".
- 나머지 offset(지평 20 의 1~3)은 보조로 같이 적는다(판정에 안 씀).

## 덧붙이는 것
- 다중검정: 같은 질문을 두 번째로 보는 것이고 8칸이다. 칸별 p 와 함께 Bonferroni(0.05/8)도 적는다.
  "관계 있다" 판정은 위 규칙 그대로 내되, Bonferroni 를 넘지 못하면 "약함" 이라고 같이 적는다.
- 보조(기술 통계, 판정 없음): 같은 8칸을 `거래소`·`코스닥` 따로.
- 첫 Q3d 와 칸별 IC 를 나란히 적어 정의 수정이 얼마나 바꿨는지 보인다.

## 끝나는 조건
8칸 판정표 + 보조표가 결과 문서에 들어가고, haiku-verifier 가 앞날 수익률·지표 표본을 DB 에서 다시 계산해 맞고,
quant-reviewer 의 CRITICAL·MAJOR 를 반영했을 때. 비용·집행이 없으니 이 결과로 매매 판단을 하지 않는다(알파 심사는 swing-it).
