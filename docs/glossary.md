# 용어집

화면과 문서에 나오는 말을 한 곳에 모았다. 식과 코드 위치는 [`formulas.md`](formulas.md) 가 정본이다.

## 주체

| 말 | 뜻 |
|---|---|
| 기관 | 금융투자·보험·투신·은행·연기금·사모 등 기관 합계. 이 저장소의 4주체 가운데 하나다 |
| 투신 | 투자신탁 — 자산운용사 펀드(`supply_demand.invtrt`) |
| 연기금 | 연금·기금 등(`penfnd_etc`). 증권사마다 범위 정의가 조금 다르다 |
| 금투 | 금융투자 — 증권사 자기매매(`fnnc_invt`). 헤지·차익 거래가 섞이므로 투신·연기금과 구분해서 본다 |
| 기타법인 | 금융기관이 아닌 일반 법인(`etc_corp`). 네 주체의 합이 0 에 가까우려면 빼면 안 된다 |
| 4주체 | 개인·외국인·기관·기타법인. 순매매 수량의 합이 0 에 가깝다 — 누가 사면 누가 판다 |

## 값과 단위

| 말 | 뜻 |
|---|---|
| 순매수 금액 | 순매매 수량 × 그날 종가(근사). DB 가 금액이 아니라 수량을 주기 때문이다 |
| VWAP | 거래량 가중 평균가 = 거래대금 ÷ 거래량. 금액 근사 오차는 종가 환산과 VWAP 환산의 차이로 잰다 |
| %p | 퍼센트포인트. 비율끼리의 차이나 시총 대비 비율에 쓴다 |
| 1년 %ile | 그 값이 최근 260거래일 분포에서 몇 번째인가(0~100). 100 은 1년 최대 매수 |
| 임펄스 | 구간 누적 순매수[억] = Σ(수량 × 그날 종가). 금액이라 큰 섹터가 늘 크다 |
| 가속 | 임펄스 ÷ 구간말 섹터 시총 × 100 [%p]. 크기를 보정한 값이고 기본 정렬이다. 물리 용어는 비유다 |
| 바구니 | 그 섹터(또는 시장)의 종목을 직접 묶은 집합. 수익률은 전일 시총 가중이고 KRX 지수가 아니다 |
| gross | 구간 안의 절댓값 합 Σ\|순매수\|. `sw-ledger` 의 `잔여몫`·`최대일몫` 분모이고, 1억 미만이면 그 비율을 안 낸다 |
| 연속 순매매 | 그날까지 순매수 부호가 같은 날 수. \|금액\| 이 그날 목록 총량의 1% 미만인 날은 연속을 끊는다 |
| 최근집중 | 5일 순매수 ÷ 이 창의 순매수 × 100. 20일 화면에서 약 25 면 고르게, 약 100 이면 최근 5일에 몰린 것이다 |

## 리포트의 지위

| 말 | 뜻 |
|---|---|
| 잠정 | 그날 저녁(18:10·재시도 19:10) 수집값으로 만든 리포트. 제목 `마감·잠정`. 마지막 날 수익률은 수집 시각까지다 |
| 확정 | 새벽 `daily_finalize` 가 덮은 값으로 다음 거래일 아침(08:20·재시도 10:20) 다시 만든 리포트. 제목 `마감·확정`, 폴더에 `FINAL.txt` |
| 재구성 | 지난 기준일을 지금 코드·지금 DB 로 다시 만든 리포트. 그날 게시본이 아니다. 제목에 `·재구성`, 폴더에 `REBUILT.txt`. 확정 실행 기록을 못 찾은 날은 `확정 기록 없음` |
| 합성 데모 | `--demo` 의 난수 리포트. 실제 시장·종목과 무관하고 제목에 `[합성 데모]` 가 붙는다 |
| 얇은 섹터 `~` | 그 구간에 거래된 종목이 10개 미만인 칸. 섹터로 읽지 않는다 |
| 탐색 모드 | `e` 로 켜는 화면. 검정이 지지하지 않는 G·선정·곱·종합을 표지와 함께 보인다. 기본은 꺼짐 |

## 증거 표지

열 이름 옆 대괄호는 그 값이 앞날 수익률에 대해 무엇을 말하는가이다. 좁은 헤더에는 줄임말을 쓴다. 정의는 [README §8](../README.md#8-주의--이-숫자들은-예측이-아니다).

| 줄임 | 전체 | 뜻 |
|---|---|---|
| `[측]` | `[측정]` | 잰 값이다. 앞날을 주장하지 않고 앞날 검정도 하지 않았다 |
| `[무]` | `[앞날 증거 없음]` | 앞날 수익률과의 순위 관계를 검정했고 증거가 없었다 |
| `[불가]` | `[판정 불가: G]` | 관문을 통과한 섹터가 날마다 2~7개라 검정력이 없다 |
| `[반전]` | `[≈섹터 20일 반전: x]` | x 는 사실상 섹터 20일 수익률 반전이고, 앞날 증거도 없다 |
| `[음]` | `[음의 순위 정보·쓸 수 없음]` | 순위 IC 가 음으로 확인됐지만 쓸 수 있는 형태로 보이지 못했다 |

## 통계

| 말 | 뜻 |
|---|---|
| ρ | 순위 상관계수(Spearman). −1~1 |
| IC | 정보 계수. 같은 날 횡단면에서 지표의 순위와 앞날 수익률의 순위가 얼마나 같이 가는가. 이 저장소의 IC 는 ρ 로 잰다 |
| OLS | 최소제곱 회귀. k 는 그 블록의 섹터 횡단면에서 가속 → 수익률로 적합한 절편 포함 OLS 기울기다 |
| k · x · ẍ | k 는 위의 기울기, x(미실현)는 적합선과 실제 수익률의 차, ẍ(풀림가속)는 x 의 2차 변화다 |
| G | 관문(얇지 않고 가속>0·미실현>0·풀림가속>0)을 통과한 섹터끼리의 순위 평균. 판정 불가 — 탐색 모드에만 있다 |
| β제거 | `sw-ledger` 동시성 화면의 `d`. 섹터별 계열에서 시장 공통 움직임을 회귀로 빼고 상관을 다시 잰다 |
| 순환이동 널 | 계열을 시간축으로 돌려 짝을 깨뜨린 비교 기준. 음의 상관 쌍이 우연이면 약 50% 다 |
