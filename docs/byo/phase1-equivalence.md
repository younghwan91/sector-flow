# BYO Phase 1 — 자기 키 sqlite 와 kr_quant 의 리포트 숫자 대조

실측 2026-11-08(일) 17:05~17:20 KST. 설계는 BYO 타당성 문서(`docs/strategy/byo-feasibility.md`, strategy-a-plus 브랜치) §2·§6 P1 이다.

**완료 조건(타당성 문서 (a)·(b), 이 조각에 한정).** 같은 기준일에 BYO sqlite 로 만든 `payload.json` 이 kr_quant 판과
- 섹터×주체 순매수 금액의 상대오차가 0.5% 이내이고,
- 섹터 수익률 차가 0.05%p 이내이며,
- 완전성 관문(`scripts/completeness_gate.py`)을 그대로 통과한다.

## 리포트 검증(`verify_report.py --db-check`) — 참고

BYO·kr_quant 조각 모두 **같은 5건**이 실패했다. 따라서 데이터 차이가 아니라 조각과 sqlite 의 성질이다.

- F 1건: sqlite `SCHEMA` 에 `delisted_stocks` 가 없다. 타당성 문서 §1.1 대로 BYO 모드에서 이 검사를 건너뛰는 분기가 필요하다.
  `verify_report.py` 는 다른 작업이 고치는 중이라 손대지 않았다(Phase 2 항목).

B 검사(조정 일봉 `high·low`)는 처음에 BYO 쪽만 실패했다. `storage.SCHEMA` 의 `daily_bars_adjusted` 에 종가 열만 있기 때문이었다.
그래서 BYO 기록기(`collect/write.py`)가 조정 표에 `open·high·low` 열을 더해 채우게 했고, 그 뒤로는 통과한다.

## 수집기 구성 (`src/sectorflow/collect/`)

- `kiwoom.py` — 표준 라이브러리 `urllib` 만 쓴다. `kiwoom-client` 는 주문 API 를 담고 있어 import 하지 않는다.
  허용 TR 6개 밖의 `api-id` 는 요청 전에 거부한다. 무효 토큰(HTTP 200 + `return_code 3`)이 오면 한 번만 재발급하고,
  다시 오면 `TokenConflict` 로 멈춘다. 429·`return_code 5` 는 백오프한다. 연속조회는 응답 헤더로 하고, 호출 상한을 둔다.
- `fetch.py` — 파싱은 quant-airflow 와 한 글자씩 같다(`to_int` 빈 값 → 0, 가격 절댓값, 천 주 단위).
- `write.py` — `storage.SCHEMA` 에 `collect_runs`(원장)·`shares_provenance`(seed/kiwoom)를 더한다. 스키마 판은 `PRAGMA user_version` 이다.
- `shares.py` — 시드 = 현재 × exp(C(시드일) − C(스냅숏일)). `market_cap_asof_bulk` 와 왕복 항등은 테스트로 고정했다.
  `reseed` 는 호출 없이 다시 계산한다.
  - 실측 중 버그 하나를 잡았다. 수정·무수정 응답이 같은 이벤트를 둘 다 실어서, 처음 판은 이벤트를 두 번 곱했다.
  - 이 실행의 시드는 `reseed` 로 고친 값이다. 바뀐 시드는 18종목이고, 분할·병합·감자 이벤트가 있는 종목 18개와 정확히 같다.
- `equiv.py` — 조각 추출·원표 대조·페이로드/수치표 대조.
- 패키징: wheel 이 `scripts/` 를 담지 않던 문제는 `force-include` 로 풀었다. 리포트 생성기 네 개와 템플릿을
  `sectorflow/_scripts/` 로 복사하고, 진입점 `sector-flow-payload`·`-numbers`·`-gate`·`-verify`·`-collect` 를 추가했다
  (`src/sectorflow/report_cli.py`). 레포 체크아웃에서는 같은 진입점이 `scripts/` 원본을 돌린다.
  확인한 것: `uv build --wheel` 로 만든 wheel 을 `uv tool install` 로 임시 도구 폴더에 설치했다. 레포 밖 폴더에서
  `sector-flow-payload`·`-numbers`·`--from-json`(viewer)·`-gate` 가 이 조각 DB 로 돌았고, 그 `flows` 는 레포 실행본과 바이트까지 같다.

## Phase 2 로 넘기는 것

1. **주식수**: DART `stockTotqySttus` 이력(대안 A)을 붙이고 이 대조를 다시 돌린다. 120일 수익률 차가 0.05%p 안에 드는지가 합격선이다.
   시드만 쓸 거라면 화면에 "과거 시총 가중치: 근사(시드)" 표지를 단다.
2. `verify_report.py` BYO 모드 — `delisted_stocks` 검사를 건너뛴다(변이 포함).
3. TR별 병렬 큐, 매일 증분(최근 15일 덮기)·확정 원장(`collect_runs`)·`finalize_done.py` 교체.

5. 403850 주식수 감소(11-03 → 11-08)가 실제인지 확인한다. kr_quant 의 다음 주간 스냅숏(11-10)과 대조하면 된다.
