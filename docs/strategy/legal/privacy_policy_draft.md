# 개인정보 처리방침 초안

> **법률 검토 전 초안.** 효력이 없고 게시하지 않았다. 유료 서비스를 열 때 실제 처리 내용에 맞춰 변호사 검토 뒤 고친다. 관련 의무는 1차 출처로 확인하지 못했다(`docs/strategy/research_notes/` legal_licensing Q4).

| 항목 | 초안 |
|---|---|
| 수집 항목 | 이메일 주소, 결제 식별값(결제대행사가 처리, 카드번호를 직접 보관하지 않음), 접속 기록 |
| 수집 목적 | 서비스 제공, 결제·환불, 제품 지원 |
| 보유 기간 | 탈퇴 시까지. 전자상거래 기록은 관계 법령이 정한 기간 {기간 확인 필요} |
| 제3자 제공 | 하지 않는다. 법령에 근거가 있을 때만 |
| 처리 위탁 | {결제대행사}, {메일 발송 업체} — 업체명·위탁 업무를 적는다 |
| 국외 이전 | {메일·호스팅이 국외면 이전국·항목·기간을 적는다} |
| 이용자 권리 | 열람·정정·삭제·처리정지를 {연락처}로 요청할 수 있다 |
| 안전성 조치 | 접근 권한 최소화, 전송 구간 암호화, {그 밖의 조치} |
| 보호책임자 | {이름·연락처} |
| 시행일 | {시행일} |

BYO 도구판은 판매자가 사용자의 데이터와 API 키를 받지 않는다. 결제에 필요한 정보만 위 표를 따른다.
