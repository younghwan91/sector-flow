## Q1. 키움증권 OpenAPI+ / REST API 약관 — 받은 시세의 재배포·상업적 이용, 가공 데이터, B2B 라이선스

### Takeaway
공개된 키움 페이지에서 시세 재배포·상업 이용을 **명시적으로 허용하거나 금지하는 문구를 찾지 못했다**. 이용 자격은 "키움 계좌 보유 고객"뿐이라, 이 API는 계좌 고객 자신이 거래에 쓰라고 주는 것으로 보인다. 받은 데이터를 제3자에게 파는 근거가 될 B2B 라이선스는 찾지 못했다. 원천 시세의 권리는 KRX에 있다(Q2).

### Cited Findings
- OpenAPI+ 안내 페이지의 이용 자격: "당사 계좌를 보유하고 HTS ID를 연결하신 고객님께서는 모두 이용 가능하며…" 재배포·제3자 제공·상업 이용·사업자 이용을 제한하는 문장은 이 페이지에 없다. — [키움 OpenAPI 안내](https://www.kiwoom.com/h/customer/download/VOpenApiInfoView)
- 같은 페이지: "비정상적인 데이터 조회에 의한 서버 부하 발생 시 임의로 접속이 차단될 수 있습니다", "관련규정에 따라 알고리즘 계좌로 한국거래소에 등록 될 수 있습니다." — [키움 OpenAPI 안내](https://www.kiwoom.com/h/customer/download/VOpenApiInfoView)
- 키움 약관 목록에는 "오픈 API 서비스 이용약관", "해외주식 실시간 시세 이용약관", "해외선물옵션 실시간 시세정보 이용약관"이 있다. **REST API 전용 약관명은 목록에 없다.** 목록에는 본문 링크가 없어(동적 로딩) 본문을 받지 못했다. — [키움 서비스약관 목록](https://www.kiwoom.com/h/customer/financeguide/VClauseListView)
- REST API 포털(openapi.kiwoom.com) 첫 화면은 하단 "서비스약관"을 위 키움 약관 목록으로 연결한다. 포털 본문에는 재배포 관련 문구가 없다. — [키움 REST API 포털](http://openapi.kiwoom.com/main/home)
- 키움은 2026-07 라이브데이터와 함께 REST API용 CLI·샘플코드를 GitHub에 공개했다. 이것은 도구 공개이지 데이터 재배포 허용이 아니다. — [아시아경제 2026-07-21](https://view.asiae.co.kr/article/2026072108591833704), [파이낸셜뉴스](https://www.fnnews.com/news/202607210926083897)

### Inferences
- 증권사가 고객에게 주는 국내 시세는 KRX(코스콤 분배)에서 받은 것이다. 증권사는 그 데이터를 고객 자신이 쓰게 할 권한만 받았을 가능성이 높다. 고객이 받은 데이터를 다시 팔 권리는 키움 약관에서 생기지 않는다고 보는 편이 안전하다. 다만 이는 업계 구조에서 나온 추론이고 약관 원문으로 확인하지 못했다. ⚖️
- 키움 쪽 리스크는 계정 차단·이용계약 해지(약관 위반, 과도한 조회)이고, KRX 쪽 리스크는 권리 침해 주장이다. 상품 매출이 키움 수집 파이프라인에 기대면 계정 하나가 단일 장애점이 된다.
- "투자자별 순매수 수량"은 KRX가 장 마감 후 공표하는 투자자별 매매동향과 같은 계열의 거래소 정보다. 키움에서 받았어도 원천 권리는 KRX 쪽이라고 봐야 한다(Q2). ⚖️

### Gaps
- "오픈 API 서비스 이용약관" 본문을 받지 못했다(약관 목록이 동적 로딩). 다음 단계: 브라우저로 약관 본문을 열어 "제3자 제공", "영리", "재판매", "가공" 조항을 확인하고 키움 OpenAPI 고객센터에 서면으로 질의한다.
- 키움의 공식 B2B·기업용 시세 라이선스 상품은 찾지 못했다.

## Q2. KRX 시장정보 이용 — 정보이용계약, 재배포 라이선스, 종가 기반 파생 통계, KRX 정보데이터시스템·OPEN API 약관, 코스콤

### Takeaway
**KRX OPEN API 약관은 비상업적 이용만 허용하고 제3자 제공을 금지한다.** KRX는 과거 분쟁에서 일별 시·고·저·종가조차 "상업적 이용은 데이터 이용료 납부와 정보이용계약 체결이 조건"이라고 답했다. 따라서 KRX 원천 데이터(지수·업종·종가·투자자별 매매)를 유료 상품에 쓰려면 KRX(또는 코스콤 등 정보분배사업자)와 계약해야 한다고 보는 것이 기본선이다. 요금표와 "파생 통계가 라이선스 대상인지"에 관한 공식 문서는 찾지 못했다.

### Cited Findings
- KRX OPEN API 이용약관 제6조②: "API 이용자는 API 서비스를 비상업적인 목적으로만 이용할 수 있으며", 이어서 결과에 대한 대가를 제3자에게 청구하는 것을 금지한다. — [KRX OPEN API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)
- 같은 약관 제11조②: "API 이용자는 한국거래소로부터 제공받은 정보를 제3자에게 제공할 수 없다." 제11조④: 이를 위반하면 이용 승인을 철회하고 서비스를 중단할 수 있다. — [KRX OPEN API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)
- 같은 약관 제11조③: 계약이 끝나면 제공받은 정보를 이용할 수 없다. — [KRX OPEN API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)
- 같은 약관 제12조③: "API 이용자가 한국거래소 통계정보를 편집하여 새로운 부가정보를 생산한 경우 한국거래소는 해당 부가정보에 대한 책임을 부담하지 아니한다." 약관은 가공물 생산을 상정하지만 그 상업적 판매를 허용하는 문구는 아니다. — [KRX OPEN API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)
- 같은 약관 제6조③: 결과 앞·뒤·중간에 다른 내용을 삽입하거나 왜곡할 수 없다. 제10조③: 결과로 화면을 만들면 "한국거래소 통계정보"를 사용했다고 표시해야 한다. 제8조④: 키당 하루 10,000회 이하. — [KRX OPEN API 이용약관](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp)
- OPEN API 이용 절차에는 "관리자 승인 후 API 서비스를 이용하여 대외 서비스 개시"라는 단계가 있다. — [KRX OPEN API 이용방법](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO003.jsp)
- 공공데이터 분쟁조정 사례: 앱 개발 목적으로 종목별 일자별 시·고·저·종가를 신청하자 KRX는 "해당 정보를 상업적으로 이용하기 위해서는 데이터 이용료 납부 및 정보이용계약 체결 등을 조건으로 하여서만 가능하다고 조건부 제공 결정 통보"했다. KRX는 2015-01-29 공공기관 지정에서 해제돼 지금은 공공데이터법상 제공 의무 대상이 아니다. — [공공데이터 분쟁조정 사례](https://www.data.go.kr/odmc/trublMdat/mdatCase/board.do?id=32)

### Inferences
- **(b) KRX 지수·업종**: OPEN API·정보데이터시스템에서 받은 지수를 유료 리포트에 그대로 싣는 것은 제6조②·제11조②에 정면으로 걸린다. 키움 경유로 받은 지수도 원천은 같다. 유료화하려면 (1) KRX 지수·업종지수를 상품에서 빼거나, (2) KRX 정보이용계약을 맺거나, (3) 라이선스를 가진 분배사(코스콤 등) 경유 데이터를 쓴다. ⚖️
- **(c) 파생 집계**(섹터×주체 순매수 합계, 백분위): "새로운 부가정보"(제12조③)의 성격이 강하지만, 약관은 가공물 판매를 허용하지 않고 제6조②는 "API 서비스를 이용한 결과"의 대가 청구를 막는다. 파생물이라고 계약상 제약을 자동으로 벗어난다고 볼 근거는 찾지 못했다. 거래소들은 보통 원 데이터를 역산할 수 없는 "non-display derived data"를 별도 범주로 두지만, KRX가 그런 범주를 두는지는 확인하지 못했다. ⚖️
- 저작권·DB권 측면: 시세 같은 사실 정보 자체는 저작권 보호가 약하다. 다만 저작권법상 데이터베이스제작자 권리와 계약(약관) 위반 책임은 별개로 남는다. 리스크의 중심은 저작권보다 계약 위반과 거래소·증권사의 공급 중단이다. (일반 법리에 근거한 해석이며 출처로 검증하지 않았다.) ⚖️
- 실무적으로 소규모 리포트 판매자가 문제되는 경로는 형사가 아니라 KRX·증권사의 권리 주장과 이용 중단이다. 매출이 생기기 전에 KRX 시장정보 담당 부서에 "종가 기반 투자자별 매매 집계의 유료 리포트 게재"가 어느 계약 범주(정보이용자/재배포)인지 서면으로 질의하는 것이 가장 싼 리스크 해소책이다.

### Gaps
- KRX "시장정보 이용 안내"의 계약 범주(정보분배사업자, 정보이용자, 실시간·지연·종가)와 요금표를 찾지 못했다. 공개 문서가 없거나 계약자에게만 제공되는 것으로 보인다. 다음 단계: data.krx.co.kr·KRX 데이터마켓플레이스의 "정보이용 안내"를 브라우저로 직접 열어 보고 KRX 시장정보팀에 문의한다.
- KRX 정보데이터시스템(data.krx.co.kr) 자체 이용약관 본문은 확인하지 못했다(위 인용은 OPEN API 약관이다).
- 코스콤 데이터 상품(CHECK, 데이터몰 등)의 가격·재배포 조건을 찾지 못했다.
- KRX 약관이 "종가 이후 파생 통계"를 예외로 두는지 확인하지 못했다.

## Q3. 자본시장법 — 유사투자자문업 신고, 투자자문업과의 경계, "관측만 하는 데이터" 서비스, 광고 규제

### Takeaway
2024-08-14 개정법 시행 후 유사투자자문업은 "**대가를 받고**, 단방향 채널로, 불특정 다수에게 **개별성 없는 조언**"을 하는 영업으로 좁혀졌다. 유료 구독자와 양방향으로 소통하면(오픈채팅·SNS 등) 미등록 투자자문업이 되어 3년 이하 징역 또는 1억원 이하 벌금이다. **"조언"이 아닌 순수 데이터 관측이 신고 대상인지에 관한 당국의 공식 유권해석은 찾지 못했다.** 유료 리포트라면 신고하거나 서면 확인을 받는 것이 보수적 선택이다. ⚖️

## Q4. 전자상거래(통신판매업), 개인정보보호법, 부가가치세

### Takeaway

### Cited Findings

## Q5. 선례 — 시장 데이터·파생 분석을 파는 국내 업체의 라이선스·신고

### Takeaway

### Cited Findings

### Inferences
- 알파스퀘어가 매매 신호를 보여 주면서도 하단에 유사투자자문업 표기가 없다는 사실은 두 가지 중 하나다. 무료·광고·증권사 제휴 모델이라 "대가" 요건을 피했거나, 단순히 홈페이지에 표기하지 않았을 수 있다. 어느 쪽인지 확인하지 못했다. FINE 조회로 확인해야 한다.
- 코스콤·KRX가 파트너로 올라 있다는 점은 실시간·종가 시세를 정식 분배 계약으로 받았을 가능성을 시사한다(추론). 솔로 개발자가 같은 길을 가려면 분배사 계약 비용이 진입 장벽이 된다.

### Gaps
- 딥서치(DeepSearch), 퀀트킹, 두물머리(불릴레오), 증권플러스 등의 유사투자자문업 신고 여부와 KRX·코스콤 데이터 계약 형태를 찾지 못했다. 다음 단계: FINE(fine.fss.or.kr) "유사투자자문업자 조회"에서 업체명을 검색하고 각 서비스 이용약관의 "데이터 제공처" 조항을 확인한다.
- 개인이 KRX 정보이용계약을 맺은 공개 사례나 요금을 찾지 못했다.

### 종합: 솔로 개발자가 할 수 있는 것 (해석, ⚖️ 변호사 확인 전제)
1. **가장 안전**: 무료·비영리로 공개하고 KRX 지수는 빼거나 출처를 표시한다. 그래도 KRX OPEN API 약관은 "제3자 제공" 자체를 금지하므로 무료 공개도 완전히 안전하지 않다.
2. **유료화 최소 조건**: (a) 데이터 공급: KRX 정보이용계약 또는 정식 분배사 경유 데이터. 키움 개인 API 데이터를 그대로 재판매하는 것은 근거가 없다. (b) 자본시장법: 단방향 유료 리포트는 유사투자자문업 신고를 기본값으로 하고 양방향 채널은 두지 않는다. (c) 사업자등록, 통신판매업 신고, 개인정보 처리방침, 환불 규정.
3. **대안 구조**: 데이터를 파는 대신 소프트웨어·도구(TUI·리포트 생성기)를 팔고 사용자가 자기 증권사 API 키로 자기 데이터를 받게 하면 재배포 문제를 피할 수 있다. 다만 해석이며, 도구가 "조언"을 내면 Q3 문제는 남는다.
4. **첫 행동**: KRX 시장정보 담당 부서에 파생 집계 유료 게재의 계약 범주를 서면 질의한다. 키움 "오픈 API 서비스 이용약관" 본문을 확인한다. 금감원 또는 변호사에게 "판정 없는 수급 관측 리포트"의 유사투자자문업 해당 여부를 묻는다.
