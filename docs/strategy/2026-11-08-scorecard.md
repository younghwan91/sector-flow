# 전략 성적표 — sector-flow 를 A++ 로 (2026-11-08 시작)

목표(사용자): 서비스의 전략적 강점을 찾고, 부족한 것은 모두 보완해 A++ 로. 전략 리뷰는 서브에이전트로 계속 돌린다.
이 파일이 원장이다. 새 세션은 여기서 출발한다.

## 전제(검증으로 확정된 것 — 바꾸지 않는다)
- 섹터 수급 지표(가속·x·G·임펄스, 섹터 투신+연기금·외국인·기관 60일)는 앞날 수익률의 증거가 없다
  (`docs/validation/2026-11-08-results.md` Q3d 재검, `2026-11-08-usefulness-results.md`).
- 종목 투신+연기금 20일 순위 정보는 통계적으로 확인됐지만 쓸 수 있는 형태는 못 보였다(같은 문서).
- 그러므로 이 서비스의 가치는 **예측이 아니라 관측**이다: "지금 누가 어디서 사고파나" 를 정확·빠르게·믿을 수 있게.
  A++ 는 예측력을 주장해서 얻지 않는다. 검증이 지지하지 않는 것을 화면이 암시하면 감점이다.
