# 첨부 A — 화면 예시 (예시 화면 — 수치는 가상)

> **법률 검토 전 초안.** 외부에 낸 적이 없다. 이 문서의 숫자·종목명·섹터명은 전부 난수로 만든 가짜이고 실제 시장·종목과 무관하다.
> `sw-flow --demo` 의 합성 데모를 폭 160 으로 그대로 뽑았다(제목 줄의 `[합성 데모]` 표지 포함, `scripts/demo_shots.py --attachment`). 실제 리포트에는 실제 종목명과 금액이 나온다.
> 데모는 표지를 다 보이려고 분봉 밖 거래 큼·거래대금 집중·권리락·잠정→확정 변경을 일부러 넣은 **확정 리포트**다. 실제 하루에 이 표지가 다 뜨는 것은 아니다. 네이버 대조 칩도 합성 값이다.
> 터미널 화면이라 색·굵기는 글자로 안 보인다 — 실제 화면은 부호를 색으로, 정렬한 열과 머리 줄을 강조 색으로 표시한다.

## 1. 첫 화면 — 오늘의 수급

**섹터를 순매수 금액 순서로 적고, 각 섹터 옆에 그날 상위 종목의 이름과 금액을 적으며(폭이 넉넉할 때), 1년 백분위 극단을 따로 뽑아 적는다.**
