# 첨부 A — 화면 예시 (예시 화면 — 수치는 가상)

> **법률 검토 전 초안.** 외부에 낸 적이 없다. 이 문서의 숫자·종목명·섹터명은 전부 난수로 만든 가짜이고 실제 시장·종목과 무관하다.
> `sw-flow --demo` 의 합성 데모를 폭 160 으로 그대로 찍었다(제목 줄의 `[합성 데모]` 표지 포함). 실제 리포트에는 실제 종목명과 금액이 나온다.
> 터미널 화면이라 색·굵기는 글자로 안 보인다 — 실제 화면은 부호를 색으로, 정렬한 열과 머리 줄을 강조 색으로 표시한다.
