# 키움증권 OpenAPI/REST API 이용약관 문의 — 파생 집계의 제3자 제공과 도구 배포

수신: 키움증권 OpenAPI·REST API 담당(고객센터) 귀하
발신: {이름} (개인 고객, 1인 개발자) / 키움 계좌 보유 고객, HTS ID: {HTS ID — 필요 시만} / {이메일} / {전화}
일자: {발송일}

## 1. 배경
저는 키움증권 계좌 고객이며, REST API로 받은 데이터로 코스피·코스닥 섹터 자금흐름을 하루 한 번 요약하는 리포트·화면(가칭 sector-flow)을 만들어 저 혼자 쓰고 있습니다.
외부에 제공하거나 프로그램을 배포하기 전에 약관상 허용 범위를 확인하려고 문의드립니다.

- **하는 일**: 섹터별·투자주체별(개인·외국인·기관·기타법인, 기관 세부 6개) 순매수 합계와, 오늘 값이 지난 1년 분포에서 몇 번째 백분위인지 표시.
- **하지 않는 일**: 종목·섹터 추천, 매수·매도 신호, 판정 점수, 수익률 예측, 주문 기능, 개별 상담.
- **자체 검증**: 사전등록 통계 검정(2026-11-08)에서 이 지표가 이후 수익률을 예측한다는 증거는 나오지 않았습니다.

## 2. 사용하는 API 데이터와 가공 방식
- 받는 데이터: 종목별 투자자별 순매매 수량, 종가, 거래량, 종목 업종 분류, 종합지수 — 장 마감 뒤 일별 조회만 하며 실시간 시세·주문 API는 쓰지 않습니다.
- 가공: 순매매 수량 × 종가로 금액을 근사해 섹터별로 합산하고, 섹터 합계의 1년 백분위를 계산합니다. 종목별 원값은 출력에 싣지 않는 형태도 검토 중입니다.
- 조회량: 하루 1~3회 배치, {대략 호출 수/일 — 기입}.

## 3. 질문 (각 항목 예/아니오와 해당 약관명·조항 번호를 부탁드립니다)
1. 개인 계좌 API로 받은 데이터를 가공한 **섹터 합계·백분위**를 **무료**로 웹에 공개하는 것이 약관상 허용됩니까?
2. 같은 가공 결과를 **유료**(구독·판매)로 제3자에게 제공하는 것이 허용됩니까?
3. 1·2번의 근거가 되는 약관은 "오픈 API 서비스 이용약관"입니까? REST API에 별도 약관이 있다면 명칭과 본문 위치를 알려 주십시오.
4. 해당 약관에 "제3자 제공", "영리 목적 이용", "재판매", "가공정보"에 관한 조항이 있습니까? 있다면 조항 번호를 알려 주십시오.
5. 가공 결과라도 원천 시세 권리가 한국거래소에 있어, 외부 제공 여부는 키움이 아니라 한국거래소에 확인해야 한다는 이해가 맞습니까?
6. 키움증권이 법인·사업자에게 시세·투자자별 매매 데이터를 재배포용으로 제공하는 **B2B 데이터 라이선스 상품**이 있습니까? 있다면 담당 부서를 알려 주십시오.
7. 제가 만든 프로그램을 배포·판매하고, 각 사용자가 **자기 키움 계좌의 API 키로 자기 컴퓨터에서** 실행해 데이터를 받는 방식(BYO)은 약관상 문제가 없습니까?
8. 7번에서 제가 사용자 데이터나 API 키를 받거나 보관하지 않는 경우, 저에게 별도 제휴·승인 절차가 필요합니까?
9. 7번 방식에서 사용자 계정의 조회 한도·알고리즘 계좌 등록 정책이 각 사용자에게 적용된다는 이해가 맞습니까?
10. 7번 프로그램 이름이나 안내문에 "키움" 명칭을 쓰는 것("키움 REST API 지원" 정도)에 제한이 있습니까?
