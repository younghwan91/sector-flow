# 서면 질의 4건 — 보내는 순서와 준비물

> **아무것도 보내지 않았다.** 네 질의서와 첨부, `../legal/` 의 약관·방침·환불 규정은 모두 **법률 검토 전 초안**이다. 외부 발송·게시는 사용자가 정한다.

전략 보고서(`../reports/섹터 수급 리포트 수익화 전략.md`)의 "1~30일 법·라이선스 선행" 단계에 쓰는 질의서다. 법률 자문이 아니다.
완료 조건: 네 곳에서 **서면(이메일·포털) 회신**을 받아 이 폴더에 `회신_<기관>_<날짜>.md`로 보관한다.

## 보내는 순서
1. **KRX (`krx_market_data.md`) — 가장 먼저.** 유료·무료·B2B 전부를 막을 수 있는 관문이고 답이 가장 늦을 것으로 본다.
2. **키움 (`kiwoom_api_terms.md`) — 같은 주에.** 답이 "KRX에 물어라"로 올 가능성이 높지만 약관 본문과 BYO 도구 배포 가능 여부(질문 7~9)는 키움만 답할 수 있다.
3. **금융위 (`fsc_advisory_scope.md`) — 첨부 D(판매 문구 초안)를 쓴 뒤.** 데이터 축과 독립이라 KRX 답을 기다릴 필요는 없다. 보내기 전 변호사 1회 검토를 받으면 질문 표현을 다듬을 수 있다(선택).
4. **OpenDART (`opendart_terms.md`) — 같은 주에.** 리포트 시총의 상장주식수에 DART 공시가 들어 있다. 답이 늦어도 다른 질의를 막지 않는다.
