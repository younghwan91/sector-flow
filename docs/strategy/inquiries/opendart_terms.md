# OpenDART 이용약관 문의 — 공시 수치(발행주식수)를 쓴 파생 집계의 제공과 도구 배포

> **법률 검토 전 초안.** 보내지 않았다.

수신: 금융감독원 OpenDART 담당 귀하
발신: {이름} (개인, 1인 개발자) / {이메일} / {전화}
일자: {발송일}

## 1. 배경
저는 개인으로 코스피·코스닥 섹터 자금흐름을 장 마감 뒤 요약하는 리포트·화면(가칭 sector-flow)을 만들어 혼자 쓰고 있습니다. 외부에 제공하거나 프로그램을 배포하기 전에 허용 범위를 확인하려고 문의드립니다.

## 2. 사용하는 데이터와 가공
- 받는 데이터: OpenDART의 발행주식수(분기 이력). 지금 DB에 23,712행(2016-03-31 ~ 2026-06-30, 2026-11-09 조회)이 있고, 수집 파이프라인이 별도로 받습니다. 공시 원문은 싣지 않습니다.
- 가공: 종가 × 그 시점 상장주식수로 종목 시가총액을 만들어 섹터 합계의 분모와 수익률 가중치로 씁니다. **출력에 발행주식수 자체는 싣지 않고** 파생값(시가총액, 비율)이 나옵니다.
- BYO 도구: 사용자가 자기 OpenDART 키로 자기 컴퓨터에서 받는 선택 기능이 있습니다(판매자는 키와 데이터를 받지 않습니다).

## 3. 질문 (각 항목 예/아니오와 해당 약관명·조항 번호를 부탁드립니다)
1. 이 수치로 만든 파생값(시가총액, 섹터 대비 비율)을 **무료**로 웹에 공개하는 것이 허용됩니까?
2. 같은 파생값이 들어간 리포트를 **유료**로 제공하는 것이 허용됩니까?
3. 출처 표시가 필요합니까? 정해진 문구가 있습니까?
4. 사용자가 **자기 OpenDART 키로 자기 컴퓨터에서** 받게 하는 프로그램을 판매·배포하는 것에 제한이 있습니까?
5. 그 프로그램 이름이나 안내문에 "OpenDART" 명칭을 쓰는 데 제한이 있습니까?
6. 키당 일일 요청 한도 외에 지켜야 할 자동 수집 조건이 있습니까?

## 4. 회신 형식
이메일 또는 서면 회신을 부탁드립니다. 담당 부서가 따로 있으면 알려 주십시오.
